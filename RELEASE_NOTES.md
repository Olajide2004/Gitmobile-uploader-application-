## 🌟 What's New in This Release

### 1. 📂 Git Trees & Commits Engine
- **Direct Folder Upload**: Commit and push full local Android folder structures directly to your GitHub repositories using GitHub Git Trees & Commits API without needing local Git CLI.
- **Dual-Track Progress Bar**: Real-time visualization tracking file scanning, blob creation, tree writing, and branch reference updates.
- **Fast Mode Optimization**: High-concurrency upload pipeline with build directory filtering (`build/`, `.gradle/`, `.git/`, `bin/`).

### 2. 🔄 Pull-to-Refresh Mechanism
- **Repository List**: Swipe down anywhere on the **Repositories** screen to fetch the latest repositories and branches from GitHub.
- **Folder Scrubber & Preview**: Swipe down on the **Upload** dashboard or tap the dedicated folder refresh icon to instantly re-scan local folder files and directory trees.

### 3. 🌐 Osunhive In-App Web Browser
- **Powered by Osunhive Technology**: Integrated high-speed, secure in-app browsing with Chrome Custom Tabs technology.
- **Default Homepage**: Configured to [https://www.osunhive.name.ng](https://www.osunhive.name.ng).
- **Developer Quick Bookmarks**: One-tap access to Osunhive official news, GitHub repositories, Personal Access Token settings, and Git REST API docs.

### 4. 📢 Live RSS News Feed & Notifications
- **Real-Time Tech News**: Live RSS feed parser reading from Osun Hive news feed.
- **System Notification Engine**: Alerts users when new tech articles and announcements are published.
- **In-App Reader**: Full reader view with bookmarking, share intent, and search filters.

### 5. 💎 Osun Hive Sponsored Website View Dialog
